# Threads Football RSS

Public RSS snapshots of the latest posts from curated football journalists on
Threads. The feeds are generated by the official Meta Threads API and consumed
by NOVA without embedding Meta or GitHub credentials in the app.

## Public feeds

- Aggregate: `https://raw.githubusercontent.com/fahimc/threads-football-rss/main/feeds/football.xml`
- Fabrizio Romano: `https://raw.githubusercontent.com/fahimc/threads-football-rss/main/feeds/fabriziorom.xml`
- Machine-readable status: `https://raw.githubusercontent.com/fahimc/threads-football-rss/main/feeds/status.json`

Individual feeds are created after the first successful API refresh. The
aggregate feed includes an RSS `lastBuildDate`, `<ttl>10</ttl>`, and a
`nova:generatedAt` timestamp.

## Refresh design

The GitHub Action runs every ten minutes and on manual dispatch:

1. Read the generation timestamp embedded in `feeds/football.xml`.
2. Exit without calling Meta when the feed is less than ten minutes old.
3. Fetch each configured exact username from the official
   `GET https://graph.threads.net/profile_posts` endpoint.
4. Retain the last successful snapshot for a profile if a later profile call
   fails.
5. Generate aggregate and per-journalist RSS files.
6. Commit changed feeds using the repository-scoped `GITHUB_TOKEN`.

NOVA only reads the public RSS. It never receives either write credential.

## One-time Meta setup

Create a Meta app with the Threads use case and obtain a long-lived Threads
user access token authorized for public profile discovery. The token needs the
`threads_basic` and `threads_profile_discovery` permissions and may require Meta
app review for production access.

Add the token as the repository Actions secret `THREADS_ACCESS_TOKEN`:

```shell
gh secret set THREADS_ACCESS_TOKEN -R fahimc/threads-football-rss
```

Then run **Actions → Update Threads football feeds → Run workflow** with
`force` enabled.

Meta references:

- [Official Threads API collection](https://www.postman.com/meta/threads/documentation/dht3nzz/threads-api)
- [Public profile posts request](https://www.postman.com/meta/threads/request/34203612-116161fc-75af-4a09-a972-66d6f64ddb10)
- [Threads API documentation](https://developers.facebook.com/docs/threads/)

## Add or remove journalists

Edit `config/journalists.json`. Usernames must exactly match the Threads handle.
An invalid or unavailable profile is reported in `feeds/status.json` without
discarding other successful profiles.

## Local verification

```shell
npm test
THREADS_ACCESS_TOKEN=... npm run update
```

The token must never be committed to this public repository.
